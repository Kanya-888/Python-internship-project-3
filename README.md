# Project 03: Personal Expense Tracker with CSV

## About
A menu-driven Python program to record and manage daily expenses.
All records are saved in a CSV file so they remain available after
the program closes.

## Features
- Add expenses with date, category, description, and amount
- View all saved expenses
- Filter by category or month
- Calculate totals for each category
- Show grand total and largest single expense
- Validate dates and amounts
- Automatically create expenses.csv

## Categories
Food, Travel, Study, Bills, Fun, and Other.

## Requirements
Python 3.10 or newer. No additional packages are required.

## How to Run
1. Open a terminal in the project folder.
2. Run:

   python project3.py

3. Choose an option from the menu.

## CSV Format
The program creates expenses.csv with these columns:

date,category,description,amount

Example:
2026-10-04,Food,Lunch,120.50
2026-10-05,Travel,Bus fare,40.00

## Data Safety
Use fictional sample expenses for demonstrations.
Do not enter bank account details or other sensitive information.
